# 2d-platformer

This is a 2D platformer game developed using **Unity and C#**. This project is being built to gain hands-on experience with game development, object-oriented programming, gameplay mechanics, and UI design.

## Current Features

- Player movement and jumping
- Enemy movement and patrol behavior
- Player death and level restarting
- Smooth screen fade transitions
- Main menu and level selection
- Pause menu and resume functionality
- Multiple playable levels
- Level completion and victory screen
- Level unlocking and saved progression

## Technologies Used

- **Unity** - Game engine
- **C#** - Gameplay and application logic
- **Git & GitHub** - Version control

## In Progress

- Next-level navigation
- Improving level transitions
- Creating additional levels
- Refining the user interface
- Improving player and enemy interactions

## Planned Features
